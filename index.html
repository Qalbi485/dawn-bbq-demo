Kaise kaam karta hai?

📱

1. Customer order kare

Menu se items choose karein, cart bharein aur "WhatsApp pe Order" dabayein.

💬

2. Admin ke WhatsApp pe order

Poora order (items, total, address, map link) admin ke WhatsApp pe ready message ke roop me aata hai. Admin ko sirf check karna hai.

✅

3. Admin approve → Rider

Admin bas message ko rider ke WhatsApp pe forward kare — rider ko items, COD amount aur map link sab mil jata hai. Koi call nahi, koi app nahi.

🛵

4. Delivery ho jaye

Rider seedha address par jaye. Admin ka poora system WhatsApp me hai — kuch chalane ki zarurat nahi.
